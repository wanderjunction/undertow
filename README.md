# Undertow

アンビエントからテクノ、ドローン、エレクトロニカまで、いろいろな電子音楽の波を、止めるまで生成し続けるプレイヤー（看板は electronic undercurrents）。
操作は「再生 / 停止」「チェンジ」「auto」「音量」と、曲調（WORLD）の切り替え。曲調は 20（これを上限にする。新しい曲調を思いついたら、どれかと入れ替える）。

## 使い方

- `index.html` をダブルクリックで開く（Chrome / Edge / Firefox / Safari）。ビルドも Node も不要
- 再生ボタン（または Space キー）で始まり、もう一度押すと 1.4 秒かけてフェードして止まる
- 再生ボタンの右のチェンジ（⏭）で、別の曲に変わる。中身は「停止 → 再生」と同じで、今の曲がフェードで引いていく間に、新しい曲が intro から始まる。停止中に押すと、そのまま新しい曲で再生が始まる。0.7 秒以内の連打は 1 回として扱う
- 音量はスライダーで。前回の値を覚えている。音量の右は、いまの曲の経過時間（チェンジや自動の曲替えで 0:00 に戻る）
- 長く聴いていると、1 曲を 15〜25 分聴いたあと、次のブレイク（静かな区間）で自動的に次の曲へつながる（ブレイクが来なければ 10 分後）。曲調を選んでいれば、その曲調のまま次の曲になる
- 再生するたびに新しい曲（seed）が生まれ、曲調・キー・テンポ・展開が変わる。画面下の `drift · 9E3779B1 · E minor · 102 BPM · current` が、曲調・曲の番号・キー・テンポ・いまの流れ

### 曲や曲調を固定する（試聴・調整用）

URL の末尾に書くと、再生とチェンジがその指定に従う。

| 書き方 | 意味 |
| --- | --- |
| `#9E3779B1` | その番号の曲を最初から再現（曲調も番号で決まる） |
| `#drift` | 曲調だけ固定（曲は毎回ちがう） |
| `#drift-9E3779B1` | 曲調と番号の両方を固定 |

- パートの役割（キック・ベース・ハット・パーカッション・スタブ・パッド・波・きらめき）とセクションの種類は、全曲調で共通。曲調が変えるのは中身だけ
- 音色は曲調ごとに一組ずつ持ち、曲調をまたいで共有しない
- 名前（`label`）は表示用なので、変えても音や動きには影響しない
- 画面下の `tide / drift / …` で選べる。曲調を選ぶと、鳴っている間ならすぐその曲調へチェンジし、止まっていればその曲調で再生を始める
- 再生ボタンの左の auto（交差する矢印）は、曲調を固定しないモード。再生・チェンジ・自動の曲替えのたびに曲調を選び直す。直前と同じ曲調は続かない
- 曲調に `hidden: true` を付けると、メニューのボタン・auto・ランダムな選曲には出てこない（URL の `#名前` なら鳴らせる）。消さずに外しておく仕組み（いま付けている曲調はない）
- いま鳴っている曲調のボタンは、文字が明るくなり、縁がその曲調の色でうっすら光る（auto で選ばれたときも）
- 画面は高さに合わせて伸び縮みし、スマホでも下の文字まで一画面に収まる。水平線は曲調ボタンの下に引く。曲調ボタンは同じ幅の格子に並べる（スマホは 5 列、幅 820 px 以上は 10 列）
- 左上の about で、アプリと曲調の説明が開く。右上の eng / 日本語 で英語と日本語を切り替えられる（選んだ方を覚えている）
- 背景（空と水平線の色、波の線の色）も曲調ごとに変わり、3 秒ほどかけて移り変わる。色は [style.css](style.css) の `:root[data-world="…"]` で決めている

## 音楽の流れ

画面下の最後の語が、いまの流れ。

| 表示 | セクション | 中身 |
| --- | --- | --- |
| still | intro | 波とパッドだけ。水面下でキックが鳴り始める |
| swell | rise | キックが水面へ上がってくる。ハット、ベース、パーカッションが加わる |
| current | groove | 四つ打ちの本流。8 小節ごとに、変えるとしても一つだけ変わる |
| deep | deep | 音数を減らし、残響の深いところへ |
| slack | breakdown | キックが引き、和音と波だけが残る（潮止まり） |

セクションとは別に、曲全体が数分かけて近づいたり遠ざかったりする（うねり）。近いときは明るく、少し大きく、乾いた音に。遠いときは少し暗く、小さく、残響の奥に。周期は約 72 / 120 / 196 小節（±2 割）の重ね合わせで、曲ごとに違う。キックとベースには掛けない

## 自分で調整するとき

| したいこと | ファイル |
| --- | --- |
| テンポの範囲、展開の長さ、パターンや和声の選び方、エコーの深さ | [js/core/worlds.js](js/core/worlds.js) |
| 音色、各パートの音量、残響やエコーへの送り量 | [js/audio/patches.js](js/audio/patches.js) |
| リズムパターンや和音の素材そのもの | [js/core/content.js](js/core/content.js) |

- 数値を少し変えたら、ブラウザで再読み込みして聴く。調子が悪くなったら git で戻せる
- 変えたあとは `npm test` で約束（キックとベースが重ならない、和音から外れない、音数の上限など）が守られているか確かめる
- 新しい曲調を足すときは、worlds.js と patches.js の両方に同じ名前で一組ずつ追加する（テストが対応を確かめる）

## 設計メモ

`Generative_Music_App_Reference_2026-09-20.md` の汎用パターンを、この規模に合わせて適用した。

- **One Writer**: 音楽状態を書き換えるのは `Director.nextBar()` だけ。状態と小節プランは凍結（deepFreeze）してから渡す
- **決定的な RNG**: `derive(seed, 目的)` で world / form / harmony / variation / drift / swell / 小節ごとの揺らぎを別々の stream にしている。同じ seed なら同じ曲になる。曲調の選択も専用の stream なので、tide の曲は v1.0 と 1 音も変わらない（v1.0 のコードと突き合わせて確認済み。v1.6 からは小節プランに「うねり」の指示が 1 つ加わるが、それ以外は同じ）
- **生成パイプライン**: フレーズ（8 小節）ごとに、Director が「どれだけ変えたいか」を決め、Generator が候補を作り、`evaluate` が変化を多軸で測り（好みを持たない）、`select` がミニマルの好み（一度に変えるのは一つまで）で選ぶ。変化の数え方は内容と聞こえ方で比べる（聞こえないパートの変化は数えない）
- **刺激の予算**: 「長い減衰 × 多い打数 × 深いディレイ」「密度と時間占有が同時に極端」「ベースとキックの低域の重なり」を避ける。上限は曲調ごとに持ち、選ぶ段階で候補を弾き、鳴らす直前にも守る
- **WORLD**: 役割とセクションは共通、中身だけを曲調ごとに持つ。音色は曲調をまたがない
- **ナイロンギター（sunset）**: 弦の音は Renderer の `pluckBuffer` / `_guitar`（パッチの `stab.guitar`）。撥弦モデル（Karplus–Strong）で、弾いた瞬間のノイズを弦の長さぶんの遅れで折り返し、折り返すたびに角を丸める（高い倍音から先に消える）。ノイズは指先の柔らかさで丸め、弾く位置の櫛形で倍音を間引く。音程の端数は 1 次のオールパスで合わせる（全音域で ±0.2 セント以内）。Web Audio の遅延の輪は約 3 ms より短くできず高い弦を作れないので、音ごとに一度だけ計算して使い回す（録音ではない。22.05 kHz で作る）。弾き方は、次の 4 つで人の手に近づけた。
  - 押さえ方（Core）: `voicing: 'guitar'` の WORLD では、和音を標準チューニングの 6 弦で押さえられる形にする（`guitarVoicing`。低い弦に根音、和音の音はすべて含む、根音の弦から 1 弦まで途切れない、指 4 本・幅 4 フレットまで、開放弦と低い位置を好む）。例: Cmaj7 = x32000、Am7 = x02010、Em7 = 020000。パッドは鍵盤の形のまま
  - 弦ごとに 1 音: 同じ弦を弾き直すと、前の音の予定を消してすぐ止める（前の音が鳴り続けて重なると、ハープやピアノのように聞こえる）
  - 手の上下: 表の 16 分はダウン（全部の弦を低い方から）、裏の 16 分はアップ（高い弦の 3〜4 本を上から、軽く速く）。強く弾くほど速く振り抜く
  - 毎回ちがう: 弦ごとに 3 つの版（ノイズと柔らかさが違う）を、前と同じにならないように選ぶ。強さ（±1 割強）、弦どうしの間（±3 割）、手の前後（-4〜+9 ms）、音程（±2 セント、強く弾いた瞬間だけ少し高い）がわずかに揺れる
  - 胴の響きは 110 / 220 Hz のふくらみ、ベースとぶつかる 90 Hz より下は切る
  - 間と余韻: 和音は 1 小節に 1 回まで（素材 `letRing`、空の小節あり）、弦 1 本ごとに 25〜45 ms かけてゆっくり鳴らし、余韻は 1.5〜4 秒。きらめきの役割はギターの単音（`glint.guitar`、D4〜A5）で、余韻はディレイと残響へ流す。和音と単音は同じ弦の音（パッチの `NYLON`）を使う
- **揺り（shore）**: ギターの単音の設定 `yuri` を持つ WORLD では、ときどき弾いたあとに音程を ±0.6 % ほどゆっくり上下させ、元の高さに戻す（箏の揺り）。中心の高さは動かさないので、和音から外れない
- **高い弦だけで刻む（skank）**: ギターの設定 `top` で、弾く弦を高い方から数本に絞る（ダブ・ギターの刻み）
- **ベースの送り**（float で使っていた。いま使う曲調はないが、echo などで流用できるので残している）: ミックスに `bassDly` / `bassVerb` を持つ WORLD だけ、ベースの出口からディレイと残響へ送る（漂うアシッドをエコーに溶かす）。ほかの曲調の音声グラフは変わらない
- **マリンバ（phase）**: 撥弦モデルで弦の真ん中を弾く（`pluckPos: 0.5`）と偶数倍音が抜け、うつろで木のような音になる。ポリメーターのアルペジオをこの音で鳴らす
- **アシッド（acid）**: TB-303 風のベースは Renderer の `_acid`（パッチの `bass.acid`）。Director はベースの型の 5 つ目の欄 `'g'` を見て「前の音から滑る」印（`from`）を付け、acid の WORLD のときだけフィルターのつまみ（`cut`、専用の stream のゆっくりした揺れ）を付ける。ほかの曲調のベースのイベントは 1 文字も変わらない（全 14 曲調を変更前と突き合わせて確認済み）。アシッドの型は和音の音だけで作り、拍の頭を避け、スライドも拍をまたがない
- **オルガンのドローン（fog）**: パッチの `pad.organ` を持つ WORLD では、パッドの和音をオルガンで鳴らす（`_organChord`）。音色はパイプの倍音（8'・4'・2 2/3'・2' …）を重ねた波形。和音の合わせ方は `justTune`: いちばん低い声部を平均律の高さに置き、すでに合わせた声部と最も合わせやすい音程（オクターブ → 5 度・4 度 → 長 3 度・短 6 度 → 短 3 度・長 6 度 → …）を持つ声部を一つずつ選んで、その声部に対して純正にする。根音からの固定の比で合わせると、m11 や sus で 5 度が 22 セント狂う（ウルフ）ので、この形にした。A m9 は 1 : 6/5 : 3/2 : 9/5 : 9/4 の純正な和音になり、A m11 は 4 度と 5 度をすべて純正にするかわりに短 3 度が 32:27 になる。声部は合わせた順（ペダル → 根音 → 5 度 → …）に一つずつ入り、和音が変わると、古い声部は後から入ったものから一つずつ引く（まだ入っていない声部は入らないまま）。`beatless` の WORLD は、波のほかに何も打たない（テストで確認）
- **909 風のドラム（motor）**: どれもパッチに書いた WORLD だけが使い、ほかの曲調の音は変わらない。キックの `drive` は tanh(k·x)/k の曲線で、小さい音はそのまま、大きい音ほど頭が丸く潰れて倍音が増える。ハットの `metal` は 808 と同じ 6 本の矩形波（205.3 / 304.4 / 369.6 / 522.7 / 540 / 800 Hz、帯域を制限して一度だけ作る）を高域だけ通したもので、ノイズを少し混ぜる。`choke` を持つハットは、次のハットが鳴るとオープンをそこで止める（ドラムマシンのハットは一つの声）。手拍子は Director が WORLD の `claps` の位置（2 拍目と 4 拍目）に毎小節置き、パーカッションの強さに従う。`machine` の WORLD は、ハットの強さ・タイミング・左右の位置を揺らさない（ドラムマシン）。ドラムマシンらしく強さは揺らさないので、乱数を使わず、motor のほかのイベントは 1 つも変わらない（全曲調を変更前と突き合わせて確認済み）。Renderer は帯域を絞ったノイズを 11 ms おきに 3 回はじき、4 回目を長く残す
- **ループ（dust）**: WORLD の `loops` を持つ曲調では、Director がスタブときらめきの代わりに `grain` のイベントを作る。層ごとに [長さ（ステップ）, 断片の中の位置, 始まりのずれ] を持ち、長さごとに同じ切り抜きを繰り返す（拍には揃えず、swing もしない）。位置は専用の stream（`derive(seed, 'loops')`）で、フレーズの境目ごとに層ごとに `find` の確率で見つけ直す。Renderer は和音ごとに一度だけ断片（`fragmentBuffer`）を計算して使い回し、切り出して鳴らす。切り口はわずかに丸めるだけなので、少し「プツッ」と鳴る（Jelinek の、切れ目の荒さがリズムになる作り方）
- **ミニマル（pulse）**: `kickTune` はキックの拍ごとの音程（半音）、`oneBar` はスタブを毎小節同じ形にする（1 小節のモチーフ）、`voicing: 'mono'` はスタブを根音 1 音だけにする。どれもその WORLD だけが使う
- **ゴースト・キック**（float で使っていた。拍を持たない fog は、キックの音色を持たずに済ませるためにだけ使う）: キックの無い曲調も、キックのパートは消さずに「音量 0 で鳴らす」。拍ごとの呼吸（サイドチェイン）、ブレイクの前に沈む流れ、ベースが拍をまたがない約束が、ほかの曲調と同じ仕組みのまま働く。キックの音を出さないのは音色（patches.js の `kick.ghost`）の判断
- **失敗も状態として表示**: Web Audio 非対応や音声の開始失敗は画面下に出す。自動で再試行し続けない
- **値の区分**: 変えない約束は CONFIRMED、試聴・計測で決めた仮値は CALIBRATION（version 付き）、曲調やジャンル固有の値は CONTENT

### 採用しなかったもの（REJECTED）

- setTimeout で 1 音ずつ鳴らす方式 → タイミングが揺れる。AudioContext の時計で小節単位に先読み予約する
- 再生中のキー・テンポ変更 → ディレイ時間と和声の整合が崩れる。一回の再生の中では固定。曲の途中の転調（案 B）も同じ理由で見送った
- 曲調ごとにパートの役割を変える → 帯域の住み分けを曲調ごとに設計し直すことになり、崩れやすい。役割は共通にした
- キックの無い曲調でキックのパートそのものを消す → 呼吸・セクションの流れ・テストの前提がまとめて崩れる。音量 0 のキック（ゴースト・キック）にした
- fog の低音を、拍と拍の間でふくらむベースで埋める → ヴォンヴォンと鳴り続けて、アンビエントにならなかった。低音は埋めない
- fog の質感を tide と同じ波（数小節ごとの寄せ返しと泡の音）にする → tide のさざ波と被る。泡の音をなくし、暗く、ゆっくりした霧の層にした
- サンプル音源 → 読み込みと権利の手間が増える。すべて合成
- ES Modules → file:// では読み込めず、ダブルクリックで開けなくなる。classic script と名前空間 `Undertow` にした

- motor の上もの: 「上ものも改良できる気がする」とのことで、和音を置くだけでなく、デトロイトらしく短いフレーズ（リフ）を繰り返すようにした（`riff`: 2 小節で一回りする 3 つの形から曲ごとに一つ。音は和音の高い方から数えた順位で持つので、和音が変わると同じ形のまま音だけ移る）。きらめきの代わりに冷たい電子音でリフを鳴らし、スタブと同じくらいの大きさ（groove で -25.7 dB 前後、スタブ -26.9）に置いた。スタブのフィルターは 16 小節で一回り開け閉めする（`sweep`）
- motor のデトロイト寄せ（その 3）: 「陰陽は印象なので、デトロイトらしさを優先して」とのことで、次を足した。スタブは根音を抜いて上の音だけで鳴らし、根音はベースに任せる（`voicing: 'rootless'`）。スタブの音色は鋸歯状波と矩形波の組（`wave2`、Juno 風）。明るいのか暗いのか分からない定番の進行（Cm9 → A♭maj7、Fm9 → E♭maj7 → Cm9）を 2 つ足して 7 つに。909 風のライドを拍の裏に薄く（`ride`、金属の響きを低めの帯域で長く）。サイドチェインの呼吸を弱める（groove 0.4 → 0.18）。ストリングスのフィルターは約 50 秒で深く開け閉めする。リフは DX7 風のベルで 3〜5 音のモチーフに。Juno 風にしたスタブが約 5 dB、ライドが大きすぎたので較正し、全体は tide より約 1.8 dB 大きい
- motor のデトロイト寄せ（その 4）: GPT に録音を分析してもらった結果（「キックとハットの床はもうデトロイト、和音もかなりデトロイト。足りないのは上に乗るものの置き方と、少し安い機械臭」「上ものは旋律として流れすぎる。音数を 3〜5 割削り、動きを小さく、置き場所を変則に」「ベースは曲を回すセルとして前へ」）を受けて、次を足した。スタブは 4 小節のうち 3・4 小節目だけ同じ形を 3 / 5 ステップ横へずらす（`stabShift`、乱数を使わない）。アタックをはっきりさせる。リフは 4 小節で一回りする 2〜3 音の塊を小節ごとにちがう位置へ置く（音数は約 4 割減、拍の頭を避け、動きは和音の上の 3 音の中だけ）。ベルは短く（減衰 1.1 → 0.55 秒）、残響を減らし、ディレイは残す。ベースの型の音程を「和音の中の順位」でも書けるようにした（`'r2'` = 根音から数えて 3 つ目の和音の音）。和音が変わっても同じ型のまま和音の音だけを弾くので、根音・5 度・7 度で回るセルがどの和音にも合う。ベースは SH-101 風（細めの鋸歯状波、音の頭だけフィルターが開く `env`）にして前に出した。ハットとライドは 909 と同じ 6 bit に量子化してざらつかせ（`bits`）、手拍子は残響を減らして乾かした。ほかの曲調は変わらない
- click はクリックが 1 小節に平均 3.3 打。最初はクリックが低く（サイン波）、高域が tide より 9 dB 少なく、ブレイクが -35.7 dB と空っぽだったので、クリックを 1 オクターブ上の三角波にし、ハットとパッドを上げた。クリックはごく短いので RMS には出にくい（高域は tide 比 -6 dB でも耳では前に出る）。拍の中の上下は 25〜26 dB と、いちばん乾いて跳ねる曲調
- acid のベースだけを鳴らすと、tide のベースより高域が 16 dB、中域が 2.4 dB 多く、低域は 3.7 dB 少ない（低音ではなく、フィルターの鳴きで前に出る）。共鳴を強くしても、ベースだけでピーク -13.3 dBFS、全体で -8.1 dBFS
- acid 0.2: GPT に録音を分析してもらった結果（「もう普通に Acid と言える。全面改修はいらない。スライドを明確に、つまみに 8〜16 小節の大きな呼吸を、アクセントは誇張していい、上ものは足さない」）を受けて 3 点だけ直した。スライドを 60 → 110 ms に長くし、滑る音はフィルターを弾き直さない（ゲートが開いたままの 303 のスライド、`slideEnv`）。つまみに 16 小節の大きな呼吸（丸いベース → だんだん開いて正体を現す → ピークで叫ぶ → また閉じる、`acid.breath`）を足し、小さな揺れは弱めた。共鳴もつまみに連動させ（閉じると丸く、開くほど鳴く、`qLow`）、アクセントはフィルターと音量を強めた。groove の大きさは変わらない（tide 比 -0.9 dB）。上ものは足していない
- dust と pulse 0.4: 「エレクトロニカ（Oval / Jan Jelinek 系）」と「役割が motor と被った pulse の作り直し」のために調べて作った（Jelinek: 60〜70 年代のジャズのレコードから 1 秒ほどのループを切り、ループの位置をホイールでずらし、わざと同期させずに少しずつちがう切り抜きを重ねてモアレを作る、切れ目の荒さや盤のプチプチをリズムにする。Robert Hood: 909・SH-101・Juno 2・DX100 と小さなシーケンサーだけ、残響も圧縮もなし、打楽器はキックとハットだけのこともあり、高いキックと低いキックを交互に使う、モチーフはたいてい 1 小節、音と音の間を大事にする）。dust の groove は tide 比 -2.0〜-3.9 dB（seed 1・2）、ループ（stab のバス）は全体より 4.3 dB 下で、キックとベースはループの下に控える。和音の断片は 1 つ作るのに 25〜38 ms（半分のサンプルレート、和音が変わるときに一度だけ）。pulse の groove は tide 比 +1.0〜+1.2 dB、モチーフは全体より 6 dB 下。最初は pulse の変化の候補が予算で 7〜10 % 全滅していた（5〜6 打のモチーフと長めの減衰で「にじみ」が上限を超える）ので、単音のスタブが短いことに合わせて予算を緩めた。単音のスタブは和音のように音量を分け合わず、2 本の鋸歯状波が同じ位相で鳴り始めてピークが上限に当たっていた（-3 dB を超える時間が 0.37 %）ので、鳴り始めをわずかにずらして音量を下げた（0.16 %、残りは出口のリミッタが受け止める）
- v1.17: 曲調を増やすのをやめ、減らす方向にした（看板は ambient minimal techno → electronic undercurrents）。役割が重なっていた deep（ドローンは fog が担う）と glass（dawn と重なる）、非表示だった ember と float を削除した（v1.16 の記録に残る）。消したのは曲調と、その曲調の名前が付いた素材（夕暮れの進行、漂うアシッドの型）だけで、流用できる仕組み（ベースの送り、m6・madd9 の和音、非表示の仕組み）は残した。残した 17 曲調の展開と鳴らす音は、削除の前と 1 つも変わらない（プランと、音声グラフへの予約をすべて突き合わせて確認）。プログラムは dust と pulse を足したうえで、v1.16 より約 150 行少ない。about の曲調の説明には、アーティストの名前を載せない
- echo 0.6: 増減は保留にして、今ある曲調の手直しへ。echo は tide とダブの役が重なっていたので、ダブテクノに振り切った（和音 1 つをほぼ動かさない、フィルターを大きく開け閉めして濡れた音にする、深いエコー、ヒスやレコードのノイズ）。新しいプログラムは足さず、ほかの曲調で作った仕組み（根音抜きの和音 `voicing: 'rootless'`、1 小節の形 `oneBar`、フィルターの開閉 `sweep`、ベースの送り `bassDly`）の設定だけで直した。groove の大きさは前と同じ（-14.8 → -14.6 dB）。ほかの曲調は変わらない
- click 0.3: クリックを乱数の位置（2 小節に 6〜10 打）から、細かく切り刻んだ 2 小節の決まった形（16 打、キックの拍を避ける）のループにし、16 分の最後を強くするアクセントと、小さな和音の置き場所のずれ（2・4 小節目）を足した。どれも既存の仕組み（`percLoop`、`accent`、`stabShift`）の設定だけ。クリックの打数が増えたぶん混み具合の上限を少し広げた。全体の大きさは変わらない（groove -17.4 dB）、クリックは +1.7 dB
- 曲調ごとの大きさ（聴感に近い重み付け、groove、seed 1）: motor -10.0、pulse -11.0、echo -11.1、tide -11.7、skank -11.8、dawn -12.4、glide -12.6、acid -12.8、sunset -13.6、click -14.0、dust -14.0、calm -14.4、moon -14.4、phase -14.7、drift -16.1、shore -16.4、fog -16.7 dB。いちばん大きかった motor に、全体の大きさのつまみ（ミックスの `trim`、パッチに書いた曲調だけ）を 0.8 で入れ、-11.9〜-12.2 dB（tide と同じあたり）にした
- drift 0.4: パッドが主役なのにパッドがほかと同じ作りで、一段劣っていたので、fog のオルガンの仕組みをストリングスのような設定（倍音 1/n、セレステ 8 セント、3 秒おきに入れ替わる声部、弱い 16' のペダル）で使い、きらめきをやめた。新しいプログラムは足していない（オルガンの検査を、ペダルの設定に合わせて一般化した）。大きさは -16.1 → trim 1.2 で -13.9〜-14.7 dB（calm・moon と同じあたり）。その後、きらめきの代わりに「残響の中へ消えていくアクセント」を入れた（きらめきの仕組みのまま、ほぼ純音の柔らかい 1 音をゆっくり消し、1 小節に 1 音まで、groove で 5〜6 小節に 1 回ほど、中音域、ほとんどを残響へ送る）。直接の音のいちばん大きい 50 ms は、パッドのそれより約 4 dB 下。さらに、ごくまれに澄んだ鈴（「チーン」）を混ぜた（motor のライドの仕組みに、鳴らす確率 `rideChance` と、金属の響きの代わりに倍音を数本だけ重ねる `tone` の設定を足して流用。3 拍目の裏で 1 小節に 1 回の機会、8 %、groove で 13 小節に 1 回ほど。音程はキーの根音か 5 度の 1 オクターブ上、倍音は 1 : 2.76 : 5.4、ハットとは別に残響へ深く送る）。最初は 808 の金属の響きのトライアングルにしたが、試聴で「欲しいのはもっときれいなチーン」とのことで入れ替えた。その後「響きが長すぎてリアリティがない」とのことで、鈴そのものの響きを短く（減衰 1.4 → 0.6 秒）、残響への送りを 1.5 → 0.8 にした。1 打の尾は、一番大きいところから 40 dB 下がるまで 7.3 秒、50 dB で 8 秒（大聖堂の残響がほとんど）
- velvet・bronze・orbit: 「キリのいい 18 に」とのことで、今の枠組みで作れて役割の被らない候補を 3 つ（ディープハウス、ガムランのテクノ、シーケンサーのスペース・ミュージック）試作し、聴き比べたうえで 3 つとも残して 20 にした（20 を上限にする）。どれも今ある仕組み（ループ、根音抜きの和音、クラップ、アクセント、決まった形の反復、回るベース、リフ、澄んだ鈴、ライドの確率）の設定だけで作り、プログラムとして足したのはループの切り出す位置の範囲（`offsets`）だけ。大きさは聴感に近い重み付けで velvet -10.9〜-11.0（trim 0.92）、bronze -12.0、orbit -12.9〜-13.2 dB
- float: 試聴で「ベースが動かない状態が続くと、他が淡いぶん単調」とのことで、同じ和音のまま動かない進行を外し、ベースの型を 2 → 5 に、つまみの周期を最大 48 → 36 小節に、変化の起きやすさを上げた。groove と deep で、同じベース・同じ和音が続く最長が 72 → 16 小節、和音が変わる回数が 100 小節あたり 4.6 → 10.3 回。大きさは変わらない（groove -23.0 dB）。その後「今度は少しせわしない、ベースの存在感がありすぎる」とのことで、ベースを奥へ下げた（直接の音 -3 dB、残響・ディレイへの送りを増やす、共鳴とアクセントを弱めて明るさの上限を下げる、滑りを 90 → 120 ms に）。変化の起きやすさは上げた分の半分ほど戻し、パッドを約 1 dB 足した。ベースだけの大きさは全体より 2.8 dB 下 → 約 5 dB 下（-25.8 → -28.7 dB）、全体は groove -23.6 dB
- phase / float / skank / shore: 最初の計測（seed 11）で groove が phase -22.5、float -26.0、skank -17.8、shore -24.6 dB とばらついていたので、1 回で合わせた（phase +1.5、float +3、skank -1.5、shore +2.5 dB）。アンビエント寄りの 3 つは drift・fog と同じあたり、skank は tide と同じあたり
- sunset: 最初の三角波のストロークは高域が中域より 17 dB 少なく、こもっていた。撥弦モデルのギターは弾いた瞬間の弦の明るさがあり、その差は 11 dB（ナイロン弦として自然な範囲）。ストロークだけの大きさは入れ替える前とそろえた（groove で約 -28〜-29 dB）。新しい和音の最初のストロークだけ弦の計算に約 8 ms、以後 0〜2 ms。キックは柔らかく、拍の中の上下は 11 dB。その後、鳴らしすぎ（1 小節に 10〜15 音のリズムギター）だったので、和音を 1 小節に 1 回までにして余韻を伸ばし、単音のフレーズを足した。和音の平均は約 2 dB 下がり（1 回ごとの強さは同じ）、単音はピーク -13 dBFS 前後（和音のピーク -9 dBFS より控えめ）。全体の高域は tide 比 -2〜-3 dB に戻った
- ember（同じタイプの曲調と比べて弱い）と float（アシッドの鳴きが漂う曲調と噛み合わない）は、試聴で外すことにした。消さずに `hidden` で非表示にしている
- glide・ember・fog・motor・click・sunset・acid・phase・float・skank・shore をそれぞれ 420 秒鳴らして NaN・クリップなし（ピーク -7.2 / -5.4 / -5.9 / -4.5 / -8.1 / -5.4 / -7.9 / -4.5 / -6.5 / -4.0 / -4.1 dBFS。tide は同条件で -6.3）
- 長く鳴らして（120〜200 秒）、全曲調で NaN・クリップなし。echo でもリミッタの天井付近に触れるのは 200 秒中 10 サンプル程度
- うねり（core-cal-0.3、voices.js の SWELL）: 最初の深さ（音量 ±0.1、トーン 2 オクターブ、残響 ±25 %）では、いちばん近い／遠いを固定して比べても全体で 0.1 dB、高域で 3 dB しか差がなく、聞き分けにくかった。今は音量 ±0.22、トーン 2.5 オクターブ、残響 ±30 %。うねりの値はほぼ ±0.7 の範囲を動き、そのとき tide の高域（2.5 kHz 以上）は 5 dB、moon は 3 dB 変わる。全体の RMS はほとんど変わらない（キックとベースに掛けないため）。遠いときは残響の量がほぼそのままで直接音だけが下がる（距離感）。calm はもともと残響が主なので変化は小さい。うねりを自由に動かして echo を 360 秒鳴らし、NaN・クリップなし（ピーク -4.3 dBFS）
- アプリと同じ逐次予約で、CPU は実時間の約 4〜8 %

これらの数値は「事故っていない」ことの確認であって、好みの最適値ではない。好みは試聴で決めている。

`.claude/launch.json` は Claude のブラウザプレビュー用の簡易サーバー設定（`python -m http.server 5178`）。アプリを使うだけなら不要。
