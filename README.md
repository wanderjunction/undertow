# Undertow

静かな波のような、アンビエントでミニマルな四つ打ちテクノを、止めるまで生成し続けるプレイヤー。
操作は「再生 / 停止」「チェンジ」「auto」「音量」と、曲調（WORLD）の切り替え。曲調は 14。

## 使い方

- `index.html` をダブルクリックで開く（Chrome / Edge / Firefox / Safari）。ビルドも Node も不要
- 再生ボタン（または Space キー）で始まり、もう一度押すと 1.4 秒かけてフェードして止まる
- 再生ボタンの右のチェンジ（⏭）で、別の曲に変わる。中身は「停止 → 再生」と同じで、今の曲がフェードで引いていく間に、新しい曲が intro から始まる。停止中に押すと、そのまま新しい曲で再生が始まる。0.7 秒以内の連打は 1 回として扱う
- 音量はスライダーで。前回の値を覚えている。音量の右は、いまの曲の経過時間（チェンジや自動の曲替えで 0:00 に戻る）
- 長く聴いていると、1 曲を 15〜25 分聴いたあと、次のブレイク（静かな区間）で自動的に次の曲へつながる（ブレイクが来なければ 10 分後）。曲調を選んでいれば、その曲調のまま次の曲になる
- 再生するたびに新しい曲（seed）が生まれ、曲調・キー・テンポ・展開が変わる。画面下の `drift · 9E3779B1 · E minor · 102 BPM · current` が、曲調・曲の番号・キー・テンポ・いまの流れ

### 曲や曲調を固定する（試聴・調整用）

URL の末尾に書くと、再生とチェンジがその指定に従う。

| 書き方 | 意味 |
| --- | --- |
| `#9E3779B1` | その番号の曲を最初から再現（曲調も番号で決まる） |
| `#drift` | 曲調だけ固定（曲は毎回ちがう） |
| `#drift-9E3779B1` | 曲調と番号の両方を固定 |

## 曲調（WORLD）

| 名前 | テンポ | 中身 |
| --- | --- | --- |
| tide | 116〜122 BPM | 静かな波の上のダブ・ミニマル。v1.0 の音（波は v1.0 より控えめ） |
| drift | 96〜104 BPM | ゆっくり漂うアンビエント。キックは柔らかく水面下に留まり、ふわふわのパッドが主役。残響は長く暗い |

| dawn | 110〜116 BPM | 明け方。唯一の長調。三角波の澄んだ和音、木琴のようなきらめき、風のような薄い質感 |
| moon | 104〜110 BPM | 月明かりの水面。質感の枠はノイズを使わず、和音の音が澄んだサイン波で、波のように 4〜10 秒かけて満ちては消える。こもった電子ピアノ風の和音、柔らかなキック、小部屋の残響 |

- パートの役割（キック・ベース・ハット・パーカッション・スタブ・パッド・波・きらめき）とセクションの種類は、全曲調で共通。曲調が変えるのは中身だけ
- 音色は曲調ごとに一組ずつ持ち、曲調をまたいで共有しない
- 名前（`label`）は表示用なので、変えても音や動きには影響しない
- 画面下の `tide / drift / …` で選べる。曲調を選ぶと、鳴っている間ならすぐその曲調へチェンジし、止まっていればその曲調で再生を始める
- 再生ボタンの左の auto（交差する矢印）は、曲調を固定しないモード。再生・チェンジ・自動の曲替えのたびに曲調を選び直す。直前と同じ曲調は続かない
- いま鳴っている曲調のボタンは、文字が明るくなり、縁がその曲調の色でうっすら光る（auto で選ばれたときも）
- 画面は高さに合わせて伸び縮みし、スマホでも下の文字まで一画面に収まる。水平線は曲調ボタンの下に引く
- 左上の about で、アプリと曲調の説明が開く。右上の eng / 日本語 で英語と日本語を切り替えられる（選んだ方を覚えている）
- 背景（空と水平線の色、波の線の色）も曲調ごとに変わり、3 秒ほどかけて移り変わる。色は [style.css](style.css) の `:root[data-world="…"]` で決めている

## 音楽の流れ

画面下の最後の語が、いまの流れ。

| 表示 | セクション | 中身 |
| --- | --- | --- |
| still | intro | 波とパッドだけ。水面下でキックが鳴り始める |
| swell | rise | キックが水面へ上がってくる。ハット、ベース、パーカッションが加わる |
| current | groove | 四つ打ちの本流。8 小節ごとに、変えるとしても一つだけ変わる |
| deep | deep | 音数を減らし、残響の深いところへ |
| slack | breakdown | キックが引き、和音と波だけが残る（潮止まり） |

セクションとは別に、曲全体が数分かけて近づいたり遠ざかったりする（うねり）。近いときは明るく、少し大きく、乾いた音に。遠いときは少し暗く、小さく、残響の奥に。周期は約 72 / 120 / 196 小節（±2 割）の重ね合わせで、曲ごとに違う。キックとベースには掛けない

## 自分で調整するとき

| したいこと | ファイル |
| --- | --- |
| テンポの範囲、展開の長さ、パターンや和声の選び方、エコーの深さ | [js/core/worlds.js](js/core/worlds.js) |
| 音色、各パートの音量、残響やエコーへの送り量 | [js/audio/patches.js](js/audio/patches.js) |
| リズムパターンや和音の素材そのもの | [js/core/content.js](js/core/content.js) |

- 数値を少し変えたら、ブラウザで再読み込みして聴く。調子が悪くなったら git で戻せる
- 変えたあとは `npm test` で約束（キックとベースが重ならない、和音から外れない、音数の上限など）が守られているか確かめる
- 新しい曲調を足すときは、worlds.js と patches.js の両方に同じ名前で一組ずつ追加する（テストが対応を確かめる）

## 設計メモ

`Generative_Music_App_Reference_2026-09-20.md` の汎用パターンを、この規模に合わせて適用した。

- **One Writer**: 音楽状態を書き換えるのは `Director.nextBar()` だけ。状態と小節プランは凍結（deepFreeze）してから渡す
- **決定的な RNG**: `derive(seed, 目的)` で world / form / harmony / variation / drift / swell / 小節ごとの揺らぎを別々の stream にしている。同じ seed なら同じ曲になる。曲調の選択も専用の stream なので、tide の曲は v1.0 と 1 音も変わらない（v1.0 のコードと突き合わせて確認済み。v1.6 からは小節プランに「うねり」の指示が 1 つ加わるが、それ以外は同じ）
- **生成パイプライン**: フレーズ（8 小節）ごとに、Director が「どれだけ変えたいか」を決め、Generator が候補を作り、`evaluate` が変化を多軸で測り（好みを持たない）、`select` がミニマルの好み（一度に変えるのは一つまで）で選ぶ。変化の数え方は内容と聞こえ方で比べる（聞こえないパートの変化は数えない）
- **刺激の予算**: 「長い減衰 × 多い打数 × 深いディレイ」「密度と時間占有が同時に極端」「ベースとキックの低域の重なり」を避ける。上限は曲調ごとに持ち、選ぶ段階で候補を弾き、鳴らす直前にも守る
- **WORLD**: 役割とセクションは共通、中身だけを曲調ごとに持つ。音色は曲調をまたがない
- **ゴースト・キック（fog）**: キックの無い曲調も、キックのパートは消さずに「音量 0 で鳴らす」。拍ごとの呼吸（サイドチェイン）、ブレイクの前に沈む流れ、ベースが拍をまたがない約束が、ほかの曲調と同じ仕組みのまま働く。キックの音を出さないのは音色（patches.js の `kick.ghost`）の判断
- **失敗も状態として表示**: Web Audio 非対応や音声の開始失敗は画面下に出す。自動で再試行し続けない
- **値の区分**: 変えない約束は CONFIRMED、試聴・計測で決めた仮値は CALIBRATION（version 付き）、曲調やジャンル固有の値は CONTENT

### 採用しなかったもの（REJECTED）

- setTimeout で 1 音ずつ鳴らす方式 → タイミングが揺れる。AudioContext の時計で小節単位に先読み予約する
- 再生中のキー・テンポ変更 → ディレイ時間と和声の整合が崩れる。一回の再生の中では固定。曲の途中の転調（案 B）も同じ理由で見送った
- 曲調ごとにパートの役割を変える → 帯域の住み分けを曲調ごとに設計し直すことになり、崩れやすい。役割は共通にした
- キックの無い曲調でキックのパートそのものを消す → 呼吸・セクションの流れ・テストの前提がまとめて崩れる。音量 0 のキック（ゴースト・キック）にした
- fog の低音を、拍と拍の間でふくらむベースで埋める → ヴォンヴォンと鳴り続けて、アンビエントにならなかった。低音は埋めない
- fog の質感を tide と同じ波（数小節ごとの寄せ返しと泡の音）にする → tide のさざ波と被る。泡の音をなくし、暗く、ゆっくりした霧の層にした
- サンプル音源 → 読み込みと権利の手間が増える。すべて合成
- ES Modules → file:// では読み込めず、ダブルクリックで開けなくなる。classic script と名前空間 `Undertow` にした

| drift | -23.5 / -7.9 | -18.7 / -5.0 | -4.6 / -5.3 / -8.2 / -7.0 / -24.7 / -27.4 |
| echo | -26.3 / -7.9 | -14.7 / -1.8 | -3.7 / -3.0 / -12.6 / -18.5 / -27.9 / -28.2 |
| dawn | -23.0 / -8.0 | -15.8 / -2.7 | -3.8 / -3.3 / -10.6 / -16.2 / -29.6 / -26.0 |
| moon | -25.0 / -6.5 | -17.3 / -2.8 | -4.5 / -3.4 / -8.2 / -15.7 / -29.9 / -27.8 |
| pulse | -26.0 / -5.5 | -14.7 / -1.1 | -4.4 / -2.5 / -12.8 / -20.2 / -25.3 / -20.8 |
| glass | -27.7 / -9.6 | -18.4 / -5.3 | -2.5 / -4.6 / -17.6 / -12.5 / -19.9 / -26.0 |
| deep | -24.8 / -8.9 | -17.9 / -5.8 | -3.2 / -5.5 / -6.5 / -17.7 / -33.9 / -39.6 |

| glide | tide 比 -1.9 | tide 比 -0.7 | （別条件の計測。下の注を参照） |
| ember | tide 比 -1.2 | tide 比 +0.6 | （同上） |
| fog | tide 比 +1.7 | tide 比 -4.1〜-4.4 | （同上） |
| motor | tide 比 -0.7 | tide 比 +0.5〜+0.6 | （同上） |
| click | tide 比 -3.7 | tide 比 -1.7〜-2.0 | （同上） |

- tide の波は v1.0 より約 6 dB 下げた（groove -35 → -40.8、intro 約 -30 → -36.4）。ほかのパートは v1.0 と同じ
- drift: 0.1 ではパッドが -17 dB と前に出すぎてリミッタに当たっていた。パッド -24、キック -23、スタブ -26.5 に較正
- echo: 0.1〜0.3 ではディレイの 1 回目の返りが原音より 10 dB 大きく、重なるたびにピークが -1 dB まで積み上がっていた。原音とほぼ同じ大きさで返る配分にし、スタブの鳴り始めを 0〜6 ms ずらし、ダブ・スローを少し浅くした
- 新しい 5 曲調: 0.1 の計測で、dawn のきらめき・glass の高い音・pulse の和音が埋もれ、deep のパッドが前に出すぎていたので較正した。pulse は和音の鳴り始めの尖りも抑えた
- moon は rain → tape → moon と 2 回コンセプトを替えた。雨音は試聴で「天ぷらを揚げる音」（尖った粒がまばら、尖度 32.6）、「ひよこの声」（音の高さが上がる水滴）、「引っ込みすぎて効いていない」（暗くした雨）。テープはヒスが常時鳴って耳に負担、揺れ（最大 7.8 セント）でソリッド感が薄れた。今は質感の枠だけを「水面の光」に替え、曲の作りと、キック・和音・パッドなどの音色は rain のまま。光の層は groove で -35.9 dB（パッド -29.8 dB の奥）。2 音で鳴らすときは 3 半音以上離す（隣り合う澄んだ音はうなりが濁る）
- glide / ember は、同じ seed の tide と並べて相対で較正した（44.1 kHz、100 秒、マスター 0.7、リミッタなし）。groove は tide -18.8 に対して glide -19.3〜-19.7、ember -18.1〜-18.3 dB。glide の高域（2.5 kHz 以上）は tide より約 3 dB 少ない（tide の高域は波の泡の分が大きい。glide はノイズを足さず、ハットときらめきで明るさを出す）。ember は意図して暗く、高域は tide より約 3 dB 少ない
- fog はキックもベースも鳴らさないので、全体の RMS は drift（tide 比 -4.3）と同じあたりに置いた。中域は tide とほぼ同じ（-0.4〜-1.2 dB）、低域は埋めない（tide 比 -11 dB）。拍の中での音量の上下（1 拍を 16 に分けた平均の最大と最小の差）は、全体・中高域とも 5.5〜6.5 dB。tide（本物のキック）は 14 / 14 dB、drift（柔らかいキック）は 8 / 5 dB、calm は 4 / 2 dB で、聞こえないキックでも拍は感じられる。最初は拍の間でふくらむベースで低音を埋めたが、ヴォンヴォンと鳴り続けてアンビエントにならなかったので外した。外すと groove が breakdown より小さくなった（-26.9 対 -25.8 dB）ので、全体を約 3 dB 上げ、groove のパッドを 0.85 → 1 にした。霧の層だけを鳴らすと、tide の波より 3 dB 小さく（-45.3 対 -42.3 dB）、2 kHz 以上は 17 dB 少ない（-65.7 対 -48.9 dB、泡の音がない）。満ち引きの幅は 6.9 dB（tide は 9.6 dB）
- motor はデトロイトらしく帯域の配分も tide に近い（低 / 中 / 高 = -19.9 / -24.4 / -37.8 dB、tide は -20.2 / -25.3 / -38.7）。スタブを 3〜4 打刻み続けるので、予算の占有を 6 → 7、伸びを 3.4 → 4 に緩めた（候補の全滅が 3.8 % → 3 % 未満）
- click はクリックが 1 小節に平均 3.3 打。最初はクリックが低く（サイン波）、高域が tide より 9 dB 少なく、ブレイクが -35.7 dB と空っぽだったので、クリックを 1 オクターブ上の三角波にし、ハットとパッドを上げた。クリックはごく短いので RMS には出にくい（高域は tide 比 -6 dB でも耳では前に出る）。拍の中の上下は 25〜26 dB と、いちばん乾いて跳ねる曲調
- glide・ember・fog・motor・click をそれぞれ 420 秒鳴らして NaN・クリップなし（ピーク -7.2 / -5.4 / -5.9 / -4.5 / -8.1 dBFS。tide は同条件で -6.3）
- 長く鳴らして（120〜200 秒）、全曲調で NaN・クリップなし。echo でもリミッタの天井付近に触れるのは 200 秒中 10 サンプル程度
- うねり（core-cal-0.3、voices.js の SWELL）: 最初の深さ（音量 ±0.1、トーン 2 オクターブ、残響 ±25 %）では、いちばん近い／遠いを固定して比べても全体で 0.1 dB、高域で 3 dB しか差がなく、聞き分けにくかった。今は音量 ±0.22、トーン 2.5 オクターブ、残響 ±30 %。うねりの値はほぼ ±0.7 の範囲を動き、そのとき tide の高域（2.5 kHz 以上）は 5 dB、moon は 3 dB 変わる。全体の RMS はほとんど変わらない（キックとベースに掛けないため）。遠いときは残響の量がほぼそのままで直接音だけが下がる（距離感）。calm はもともと残響が主なので変化は小さい。うねりを自由に動かして echo を 360 秒鳴らし、NaN・クリップなし（ピーク -4.3 dBFS）
- アプリと同じ逐次予約で、CPU は実時間の約 4〜8 %

これらの数値は「事故っていない」ことの確認であって、好みの最適値ではない。好みは試聴で決めている。
